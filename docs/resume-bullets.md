# Resume bullets (numbers come from the committed reports; re-check after any change)

- Built **Warden**, a zero-trust access broker (Python, FastAPI, Cedar, Keycloak, DuckDB) that issues short-lived, scoped agent identities via OAuth token exchange (RFC 8693) and enforces RBAC, ABAC and ReBAC with an agent-scope-intersect-user rule; validated against a live Keycloak and a hash-chained audit log.
- Authored three red-team corpora (107 + 40 + 21 attacks, 220 benign tasks) covering indirect prompt injection, confused deputy, privilege escalation and exfiltration; authorization alone let 51% of the first set and 92% of the hard set execute.
- Evaluated every control in isolation (precision, recall, F1, Wilson and bootstrap intervals) and against a local LLM as the victim agent (31.5% obeyed injections unprotected, 0% behind Warden); found that the first corpus overstated defences (0% executed vs 17.5% on a held-out set), then hardened the stack and cut a second held-out set from 67% to 0% executed at the cost of 3 extra approvals.
- Built DuckDB/SQL access analytics, NetworkX attack-path graphs and replay-validated least-privilege policy diffs (also run on 1.9M public CloudTrail events), plus a GitHub Actions gate that fails builds when attacks execute or false blocks rise.
- Ran a simulated compromised-agent incident end to end (detection in 90 simulated seconds, revocation, scope reduction, zero data delivered) and documented what still failed in a postmortem.
